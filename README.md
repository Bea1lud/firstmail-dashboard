# firstmail-dashboard
FirstMail Dashboard — веб-приложение для мониторинга IMAP-ящиков и автоматического извлечения кодов подтверждения из писем.  Поддерживает одновременную проверку до 20 аккаунтов, фильтрацию писем по сервисам (Telegram, Twitch, TikTok, Discord, Steam и др.), отображение отправителя, темы письма, времени получения и найденного кода подтверждения.
